# Repository guide

Start with the README for the problem, runnable entry points, implementation and limitations. The original detailed README is preserved in `README-ORIGINAL.md`; no implementation claims or caveats were removed in the visual refresh.

## Working with the project

1. Read the documented prerequisites and configuration.
2. Run the local non-network examples and tests before enabling optional integrations.
3. Inspect the source directories and existing tests for the behavior being changed.
4. Keep credentials, local environments and generated reports out of commits unless explicitly intended as sanitized examples.
5. Record the exact commands and results used to validate a change.

## Presentation assets

`docs/assets/banner.svg` is an editable vector banner with accessible title and description. Documentation links use repository-relative paths so they continue working in clones and GitHub previews.

## Validation boundary

This update improves documentation and repository presentation. Historical measurements and verification statements remain attributed to their original runs. No new external model call or production deployment is claimed.
